# Domain Docs

How engineering skills should consume this repository's domain documentation.

## Before exploring

Read the root `CONTEXT.md` and any relevant ADRs in `docs/adr/` before exploring or changing domain behavior.

## Layout

This is a single-context repository:

- `CONTEXT.md` contains the shared domain glossary.
- `docs/adr/` contains repository-wide architecture decision records.

## Vocabulary

Use terms defined in `CONTEXT.md` in issue titles, proposals, hypotheses, and tests. If output conflicts with an ADR, call out the conflict explicitly rather than silently overriding it.
